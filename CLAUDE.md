# Project rules

This repo (live-demo) follows the mandatory standards in `skills/standards/`.

- Before changing code, prompts, data or docs, read `skills/standards/per-repo.md` (section for live-demo) and `skills/standards/common.md`.
- Use the stage, level, channel and control-kind names exactly as in `skills/standards/data-model.md`.
- Cite rule ids (C-xx, A-xx, L-xx) in reviews. Safety (C-04) and privacy (C-05) have no exceptions.
- Before merging, run the `release-gate` skill.
- `skills/` is the harness repo. Change standards and skills there, not here.
